# 📖 線上班級聯絡簿 (Online Contact Book)

一個輕量、美觀、免伺服器維護的**線上班級聯絡簿**系統，完美支援手機與電腦瀏覽（RWD），可直接免費託管於 **GitHub Pages**。

---

## ✨ 核心特色

1. **四大分類清楚條列**：
   - 📝 **今日作業**：科目標籤、作業詳細內容、繳交期限。
   - 📋 **測驗考試**：科目、測驗範圍、考試節次或日期。
   - 📦 **物品／回條繳交**：收費、重要回條、學用品、截止日期。
   - 📢 **提醒事項**：作息變動、重要公告、全校活動、攜帶物品。
2. **權限分離（知道連結的人才能編輯）**：
   - **一般公開網址**（給家長與學生）：純唯讀檢視，介面清爽無編輯干擾。
   - **專屬秘密連結**（給導師/管理員）：網址帶有加密管理授權，開啟後自動解鎖新增、修改、刪除與一鍵發布功能。
3. **實用貼心工具**：
   - 📅 **日期切換**：快速前後天瀏覽或點選日曆選擇特定日期。
   - 📱 **一鍵複製 LINE 格式**：自動轉成適合貼入 LINE 班級家長群組的整齊條列文字。
   - 🖨️ **友善列印**：專屬列印樣式，可一鍵轉為乾淨的 A4 紙本或 PDF。
4. **零後端架構（Zero-build & Free）**：
   - 不需要架設後端伺服器或資料庫。
   - 資料透過 GitHub REST API 直接儲存於 repository 的 `data/records.json`，永久免費且具備完整的版本修改歷史。

## 🚀 GitHub Pages 5 分鐘免費託管部署教學

### 步驟 1：建立 GitHub 儲存庫 (Repository)
1. 登入您的 [GitHub 帳號](https://github.com/)。
2. 點選右上角 `+` -> **New repository**。
3. 輸入專案名稱（例如：`online-contact-book`），設為 **Public**（公開），然後點選 **Create repository**。

### 步驟 2：上傳專案檔案
將本專案目錄內的所有檔案上傳到該 Repository 的根目錄：
- `index.html`
- `data/records.json`
- `js/github-sync.js`
- `js/app.js`
- `README.md`

> 💡 可使用 GitHub 網頁版介面直接拖曳上傳（Upload files），或使用 Git 命令列：
> ```bash
> git init
> git add .
> git commit -m "Initial commit"
> git branch -M main
> git remote add origin https://github.com/<你的GitHub帳號>/online-contact-book.git
> git push -u origin main
> ```

### 步驟 3：啟用 GitHub Pages 免費網站
1. 在該 GitHub 儲存庫頁面，點選上方的 **Settings**（設定）。
2. 在左側選單點選 **Pages**。
3. 在 **Build and deployment** 下方的 **Source** 選擇 **Deploy from a branch**。
4. **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，按下 **Save**。
5. 等待約 1~2 分鐘，頁面上方會出現您的公開網站網址：
   ```
   https://<你的GitHub帳號>.github.io/online-contact-book/
   ```

## 🔑 如何設定「只有知道連結的人才能編輯」？

GitHub Pages 本身是靜態網頁，本系統透過 **GitHub Fine-grained Personal Access Token** 結合專屬網址 Hash，讓只有拿到專屬秘密連結的人具備修改與存檔權限：

### 步驟 1：產生一組專用的 GitHub Token
1. 點擊 GitHub 右上角個人頭像 -> **Settings** -> 左側最下方 **Developer settings**。
2. 選擇 **Personal access tokens** -> **Fine-grained tokens** -> 點選 **Generate new token**。
3. 設定名稱：例如 `contact-book-editor`。
4. **Expiration**（有效期限）：可依學期設定（例如 90 天或客製更久）。
5. **Repository access**：選擇 **Only select repositories**，並選取剛建立的聯絡簿儲存庫（例如 `online-contact-book`）。
6. **Permissions** -> **Repository permissions**：
   - 找到 **Contents**，將權限設為 **Access: Read and write**（讀取與寫入）。
7. 點選最下方 **Generate token**，並複製產生的金鑰（格式為 `github_pat_...`）。

| 通行密碼類型 | 預設密碼 | 可使用之功能權限 | 適用人員 |

### 進入編輯／管理模式的方式：

#### 方法 1：點擊「編輯登入」手動輸入密碼
1. 開啟聯絡簿網站，點擊右上角或頁尾的 **「🔒 編輯登入」**。
2. 在彈出視窗輸入密碼：
   - 輸入 `180156`：解鎖**專屬管理員模式**（出現「📢 班級公告」與「⚙️ 密碼／同步設定」）。
   - 輸入 `6830`：解鎖**一般編輯模式**（可編輯四大分類項目）。
3. 若以 `6830` 登入後欲進一步管理公告，可隨時點選上方「🔑 管理員解鎖」並輸入 `180156` 升級權限。

#### 方法 2：使用帶有密碼的專屬秘密網址（免手動輸入密碼）
系統支援透過網址 Hash 自動授權，可私下將專屬網址傳給授權人員加入書籤或加入手機主畫面：
- **專屬管理員專用網址**：
  ```text
  https://<你的GitHub帳號>.github.io/online-contact-book/#180156
  ```
- **一般編輯人員專用網址**：
  ```text
  https://<你的GitHub帳號>.github.io/online-contact-book/#6830
  ```

## 📅 多日跨期自動同步（設定期限如 3 天後，期間聯絡簿天天自動同步）

系統內建智慧跨期日期演算：
1. **自動跨日顯示**：若新增一筆作業或繳交事項時設定了截止日（例如設定為 3 天後），**從發布當天起算，直到截止日當天，這幾天的聯絡簿都會自動同步列出該項目**！
2. **過期自動隱藏**：截止日隔天起，系統自動下架隱藏，確保每日聯絡簿乾淨俐落。
3. **即時剩餘天數提醒**：
   - 進行中項目會以徽章標明：`⏳ 期限至 2026-09-11（剩 2 天）`
   - 截止日當天會以鮮明紅字標明：`🚨 今日截止`
   - 非首日延續項目會貼心附註：`📌 延續自 2026-09-08`
4. **LINE 複製自動同步**：切換至明日或後天的聯絡簿並點選「複製 LINE」時，自動帶入該日所有進行中與截止項目，並清楚標註剩餘天數！

## ⚡ 如何實現「免輸入繁瑣資訊，直接同步進倉庫」？

為避免每次發布都要手動輸入帳號、倉庫名稱或金鑰，系統支援兩種**「零繁瑣直接同步」**方式：

### 推薦方式 A：直接在 `js/config.js` 填入 Token（全體設備秒級同步）
1. 開啟專案內的 [`js/config.js`](file:///C:/Users/fyi10/.gemini/antigravity/scratch/online-contact-book/js/config.js) 檔案。
2. 將您的 GitHub Token 填入 `token: 'github_pat_xxxx'`。
3. 儲存並推送到 GitHub 倉庫。
4. **完成！** 此後任何人在任何手機或電腦上，只要輸入密碼 `6830` 或 `180156`，點擊右上角**「發布變更」**，系統將**直接秒級同步 Commit 到 GitHub 倉庫**，完全不需要輸入任何繁瑣資料！

### 方式 B：傳送「免設定直接同步網址」給協作者（無須手動設定）
1. 以管理員密碼 `180156` 登入後，點選上方「⚙️ 密碼／同步設定」。
2. 貼入一次 Token，點選下方**「複製 🚀 協作者免設定直接同步網址」**（網址格式如 `https://.../#6830&token=...`）。
3. 私下傳給小老師或幹部。協作者點開該連結後，瀏覽器便會永久記憶同步授權，點擊「發布變更」即可直接同步進倉庫！

> 💡 **自動網址偵測**：系統部署在 GitHub Pages 時，會**自動從網址解析 GitHub 帳號與倉庫名稱**，完全不需要手動填寫！

## 💻 本機快速預覽測試

若要在本機進行測試，可在專案目錄啟動任意本地靜態伺服器：

```bash
# 使用 Python 內建伺服器
python -m http.server 8000
```

- 開啟 `http://localhost:8000`：預設唯讀訪客模式。
- 點擊「編輯登入」輸入 `6830`：測試一般編輯模式。
- 點擊「編輯登入」輸入 `180156`：測試專屬管理員模式（解鎖班級公告與密碼設定）。
- 或直接在網址後方加上 `#180156` 或 `#6830` 測試免輸入密碼直接解鎖。
